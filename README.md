# Epitech PHP Pool

This repository contains the exercises completed during the PHP pool at Epitech. The pool is a intensive coding bootcamp where students learn PHP fundamentals, object-oriented programming, and web development basics.

## 📚 Description

The PHP pool is designed to introduce students to web development using PHP. Through daily exercises, students progressively learn:
- PHP syntax and fundamentals
- Variables, functions, and control structures
- Object-Oriented Programming (OOP)
- Classes, inheritance, and interfaces
- Abstract classes and polymorphism
- Web forms and HTTP methods
- Database interactions with PDO
- Session management

## 📂 Repository Structure

The repository is organized by days, with each day containing multiple exercises:

```
pool_php/
├── phpday01/    # PHP basics, variables, and simple operations
├── phpday02/    # Functions, arrays, and control structures
├── phpday03/    # Introduction to OOP - Classes and constructors
├── phpday04/    # OOP - Properties and methods
├── phpday05/    # OOP - Inheritance and polymorphism
├── phpday06/    # OOP - Abstract classes and interfaces
├── phpday08/    # Web development - Forms and HTTP
└── phpday09/    # Database interactions with PDO
```

## 🚀 Getting Started

### Prerequisites

- PHP 7.0 or higher
- A web server (Apache, Nginx) or PHP built-in server
- MySQL/MariaDB (for Day 09 exercises)

### Running the Exercises

#### For standalone PHP files:
```bash
php path/to/exercise/file.php
```

#### For web-based exercises (Day 08 and 09):
```bash
# Using PHP built-in server
cd phpday08/ex_01
php -S localhost:8000
```

Then open your browser at `http://localhost:8000`

#### Example:
```bash
# Run Day 01, Exercise 01
php phpday01/ex_01/ex_01.php

# Run Day 03, Exercise 01
php phpday03/ex_01/Gecko.php

# Run Day 08 web exercise
cd phpday08/ex_01
php -S localhost:8000 index.php
```
